Замовлення

Кошик і «Купити в 1 клік». Натисніть на замовлення, щоб змінити статус, вписати ТТН і написати клієнту.

Ціни в замовленні — ті, що бачив клієнт на сайті; звіряйте їх під час підтвердження. Список оновлюється сам щохвилини.

Заявки

Дропшипінг, опт, постачальники, франшиза й вакансії — усі запити з сайту в одному місці.

Відгуки

Ключ GitHub — публікація з адмінки

Потрібен, щоб публікувати відгуки й змінювати націнку в 1 клік. Ключ зберігається лише в цьому браузері й нікуди не надсилається, крім GitHub.

  1. Відкрийте створення ключа на GitHub (в акаунті, де лежить сайт).
  2. Назва — будь-яка, термін дії — 1 рік. Resource owner — Dev-Geniy. Repository access → Only select repositories → оберіть stroyshopua (не «Public repositories» — так ключ лише читає).
  3. Нижче в Permissions з’явиться блок Repositories → Add permissions → Contents → поставте Read and write. Блок «Account» не чіпайте. Натисніть Generate token, скопіюйте кнопкою 📋 і вставте нижче.

Націнка на товари

Ціна на сайті = ціна постачальника DROPOFFICE + націнка. Після збереження ціни оновляться за 3–5 хвилин.

Пошукові системи

Додайте сайт один раз — і Google та Bing швидше знаходитимуть нові товари й статті. Карта сайту оновлюється автоматично, а нові сторінки самі надсилаються в Bing через IndexNow.

  • Google Search Console — додайте samostroy.shop і карту сайту sitemap.xml
  • Bing Webmaster Tools — можна імпортувати сайт із Google одним кліком
  • Google Merchant Center — безкоштовні товарні оголошення в Google
  • Карта сайту · robots.txt · llms.txt

Корисне

  • Оновлення сайту на GitHub — чи пройшла остання синхронізація каталогу
