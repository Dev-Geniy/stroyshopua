# Сторож сайту й скриптів

Кожні ~15 хвилин GitHub сам перевіряє:
- **сайт** samostroy.shop відкривається;
- **каталог і ціни** оновлювалися не пізніше ніж 30 годин тому (інакше — застарілі ціни/наявність);
- **три скрипти Google**: замовлення сайту, кабінет партнерів, вітрини (і що їхні таблиці відкриваються);
- **Telegram-боти**: адмін-бот, а також бот клієнтів і Drop-бот, якщо додати їхні токени.

Якщо щось не працює (перевіряє двічі з паузою, щоб не тривожити через секундний збій) — в адмін-бот приходить
🔴 з поясненням, що саме зламалось, що через це не працює для людей і куди дивитися. Нагадування — раз на 3 години,
поки не полагодиться. Коли запрацює — 🟢 «знову працює» з часом простою.

## Увімкнути (5 хвилин, один раз)
1. GitHub → репозиторій **stroyshopua** → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
2. Додайте секрети (Name → Secret → **Add secret**):
   - `ADMIN_BOT_TOKEN` — токен адмін-бота (той самий, що `BOT_TOKEN` у властивостях основного скрипта);
   - `ADMIN_CHAT_ID` — ваш ID чату з адмін-ботом (той самий `CHAT_ID`; кілька — через кому);
   - необов’язково: `CLIENT_BOT_TOKEN` і `DROP_BOT_TOKEN` — щоб перевіряти й цих ботів.
3. Перевірка: **Actions** → «Сторож сайту й скриптів» → **Run workflow** → залиште галочку «report» → **Run workflow**.
   За хвилину в адмін-бот прийде «✅ Сторож: усе працює» зі списком перевірок.

Далі сторож працює сам. Звіт у будь-який момент — так само через **Run workflow**.

## Глибока перевірка скриптів
Скрипти відповідають на `?health=1` і заодно перевіряють, що їхня таблиця відкривається. Це є в свіжих версіях
`tools/main-api/Code.gs`, `tools/partner-api/Code.gs`, `tools/vitryna-api/Code.gs`. Зі старим кодом сторож теж
працює — лише перевіряє, що скрипт відповідає.

## Що робити, коли прийшло 🔴
- **«просить увійти в Google»** — Розгорнути → Керувати розгортаннями → ✏️ → «Хто має доступ»: **Усі** → Розгорнути.
- **«адресу скрипта не знайдено (404)»** — розгортання архівовано або змінилась адреса. Створіть нове розгортання й надішліть адресу, щоб оновити config.js.
- **«помилка скрипта …» / «відповідає не JSON»** — Apps Script → ліворуч **«Виконання»**: остання червона рядок покаже помилку. Найчастіше — треба знову натиснути «Виконати» на будь-якій функції й дати дозволи.
- **«HTTP 5xx / ліміт»** — тимчасовий збій Google або вичерпано денний ліміт; зазвичай минає сам.
- **«Каталог не оновлювався»** — GitHub → Actions → «Синхронізація товарів і сторінок сайту»: подивіться останній запуск.
- **Бот: «повідомлення не доходять до скрипта»** — у відповідному скрипті запустіть `setupBots` (основний) або «Підключити бота» в адмінці.

## Вимкнути
GitHub → Actions → «Сторож сайту й скриптів» → ⋯ → **Disable workflow**. Або видаліть `.github/workflows/watchdog.yml`.
