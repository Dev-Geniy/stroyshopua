# Меню внизу екрана в ботах

| Бот | Кнопки |
|---|---|
| **Адмін-бот** (основний скрипт) | 📊 Сьогодні · 🆕 Нові · 🔎 Пошук · 🌐 Адмінка |
| **Samostroy Shop бот** — для покупців (основний скрипт, `CLIENT_BOT_TOKEN`) | 🛍 Каталог (відкриває сайт у Telegram) · 📦 Мої замовлення · 🚚 Доставка й оплата · 🧰 Як клеїти (інструкції з монтажу) · 🔁 Обмін і повернення · 💬 Менеджер |
| **Samostroy Drop бот** — для партнерів (скрипт партнерів, `DROP_BOT_TOKEN`) | ➕ Нове замовлення · 📦 Мої замовлення · 💰 Заробіток (місяць, у роботі, до виплати, виплачено, до наступного рівня, челендж) · 🏪 Моя вітрина · 🎓 Допомога (база знань, PDF, курси, менеджер) · ⚙️ Налаштування |
| Drop-бот для гостя (ще не партнер) | 🚀 Стати партнером · ❓ Як це працює · 💬 Менеджер |

Меню з’являється після /start, після підключення Telegram чи реєстрації, а також у відповідь на будь-яке повідомлення. Сховалося — значок ⌨️ біля поля вводу або /menu.
Звичайний текст (не кнопка) як і раніше йде менеджеру.

## Увімкнути
1. **Основний скрипт** (`BOT_TOKEN`, `CLIENT_BOT_TOKEN`) → код з https://raw.githubusercontent.com/Dev-Geniy/stroyshopua/main/tools/main-api/Code.gs → 💾 → **Розгорнути → Керувати розгортаннями → ✏️ → Нова версія**. За бажання — **setupBots** ▶, щоб у списку команд з’явилась /menu.
2. **Скрипт партнерів** (`DROP_BOT_TOKEN`) → код з https://raw.githubusercontent.com/Dev-Geniy/stroyshopua/main/tools/partner-api/Code.gs → 💾 → **Нова версія** розгортання.
3. Один раз у скрипті партнерів: **menuRollout** ▶ — усім партнерам з Telegram прийде коротке повідомлення з новим меню (інакше вони побачать його після наступного /start чи повідомлення). За бажання — **botDecor** ▶, щоб оновити список команд.
