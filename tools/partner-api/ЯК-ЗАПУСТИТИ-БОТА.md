# Telegram-бот партнерів «Samostroy Drop» + Mini App (≈10 хвилин, один раз)

Бот працює на тому самому скрипті кабінету партнерів (`tools/partner-api/Code.gs`), що вже підключений до сайту.
Партнери відкривають бота → кнопка «Кабінет» → застосунок https://samostroy.shop/app/ прямо в Telegram:
реєстрація або вхід, дашборд заробітку, нове замовлення з каталогу, статуси й ТТН, товари з текстами оголошень, профіль.

## 1. Створіть бота
1. У Telegram відкрийте **@BotFather** → `/newbot`.
2. Назва: **Samostroy Drop**. Ім’я (закінчується на `bot`), напр. **SamostroyDropBot**.
3. BotFather надішле **токен** (вигляд `123456789:AA…`). Скопіюйте його.
4. (Необов’язково) там же: `/setuserpic` — логотип, щоб бот виглядав солідно.

## 2. Оновіть скрипт кабінету партнерів
1. Відкрийте таблицю **«Samostroy — партнери»** → **Розширення → Apps Script**.
2. Виділіть увесь код у `Code.gs` і замініть вмістом нового файлу
   https://raw.githubusercontent.com/Dev-Geniy/stroyshopua/main/tools/partner-api/Code.gs (Ctrl+A → Ctrl+C → вставити) → 💾 **Зберегти**.
3. ⚙️ **Налаштування проєкту** → **Властивості скрипта** → **Додати властивість**:
   `DROP_BOT_TOKEN` = токен з кроку 1 → **Зберегти властивості скрипта**.
4. **Розгорнути → Керувати розгортаннями** → олівець ✏️ → Версія: **Нова версія** → **Розгорнути**.
   Google попросить нові дозволи (надсилати запити в Telegram, створювати розклад) → свій акаунт → «Додатково» → «Перейти до проєкту» → **Дозволити**.
   Адреса скрипта не змінюється — у `config.js` нічого міняти не треба.

## 3. Підключіть бота в адмінці
1. https://samostroy.shop/admin.html → **Налаштування** → блок **«Telegram-бот партнерів»**.
2. **«Підключити бота»** — скрипт сам налаштує прийом повідомлень, кнопку «Кабінет», команди й опис бота.
3. **«Підключити мій Telegram для сповіщень»** → «Мій особистий чат» (або «Додати в групу менеджерів») → у Telegram натисніть **«Почати»**.
   Тепер нові партнери й замовлення партнерів приходять туди з кнопками.
4. **«Тестове повідомлення»** — перевірка.

Готово. Посилання для партнерів: `https://t.me/<ім’я вашого бота>` — додайте його в розсилки, анкету, пости.

## Що вміє бот
**Партнер:**
- `/start` — меню: Відкрити кабінет, Нове замовлення, Мої замовлення, Товари.
- Mini App: реєстрація за 1 хвилину (номер можна взяти з Telegram) або вхід у наявний кабінет з сайту (телефон + пароль).
- Сповіщення: замовлення прийнято → підтверджено → відправлено (ТТН + кнопка «Відстежити») → клієнт забрав → виплачено; коментарі менеджера; новий рівень.
- Будь-яке повідомлення в бот іде менеджеру; відповідь менеджера приходить у бот.
- Партнер, що зареєструвався на сайті: **Профіль → «Підключити Telegram»**.

**Менеджер (у підключеному чаті):**
- Картка кожного замовлення партнера з кнопками: **✅ Підтвердити**, **🚚 Відправлено · ТТН** (бот попросить номер — надішліть його відповіддю), **📬 Отримане**, **↩️ Повернення**, **❌ Скасувати**. Партнер одразу отримує сповіщення.
- Відповідь (Reply) на повідомлення партнера — піде партнеру.
- `/id` — показати ID чату.

Усе, що менеджер змінює в адмінці → Партнери (статус, ТТН, коментар, виплата), теж надсилається партнеру в бот.

## Якщо бот не відповідає
Адмінка → Налаштування → блок бота показує стан і останню помилку Telegram.
1. Натисніть **«Підключити бота»** ще раз.
2. Якщо помилка повторюється — **Ще → «Резервний режим»**: скрипт сам забирає повідомлення щохвилини (відповідь бота — до 1 хвилини, Mini App працює як завжди).
3. Після будь-якої зміни коду скрипта — **Нова версія** розгортання (крок 2.4).

## Видалення записів в адмінці
- **Замовлення, заявки, відгуки сайту**: у картці запису кнопка **«Видалити»**. Запис зникає з адмінки, списків і аналітики; список видалених зберігається в таблиці кабінету партнерів (аркуш «Видалені записи сайту»). Рядок в основній таблиці сайту лишається — так номери нових замовлень не збиваються. Відновити: вкладка **«Видалені»** → запис → **«Відновити»**. Опублікований відгук при видаленні знімається й зі сторінки відгуків (потрібен ключ GitHub).
- **Замовлення партнерів і партнери**: кнопки «Видалити» в картках (Адмінка → Партнери). Видаляються назовсім, копія — в аркуші «Архів видаленого».

## Що де
- Аркуші таблиці «Samostroy — партнери»: «Партнери» (нові стовпці «Telegram ID», «Telegram»), «Замовлення партнерів» (новий стовпець «Канал»: Сайт / Telegram), «Видалені записи сайту», «Архів видаленого».
- Mini App: `app/index.html`, `app/app.js`, `app/app.css`; каталог для нього `app/catalog.json` оновлюється автоматично разом із товарами сайту.
- Властивості скрипта, які бот заповнює сам: `BOT_USER`, `BOT_MODE`, `TG_SECRET`, `DROP_ADMIN_CHATS`, `LAST_P`, `LAST_Z`. Не видаляйте їх.
