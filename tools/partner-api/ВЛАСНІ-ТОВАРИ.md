# Власні товари партнерів (товари, яких немає в каталозі)

**За замовчуванням вимкнено.** Партнер не бачить цієї можливості, поки ви не ввімкнете її саме для нього.

## Як увімкнути партнеру
Адмінка → **Партнери** → картка партнера → **Можливості** → ☑ «🧩 Власні товари» → **Зберегти**. Партнеру прийде повідомлення в бот.

## Що робить партнер
Кабінет → **Мої товари** → блок «🧩 Власні товари» → **Додати свій товар**: фото з телефона (до 5, перше — головне), назва, ціна для покупця, категорія, артикул, опис, наявність → «Надіслати на перевірку».
- Товар одразу видно в його списку зі статусом **⏳ На перевірці / ✅ Схвалено / ✖️ Не схвалено** (з причиною).
- Будь-яка зміна (назва, ціна, фото, опис) — товар знову йде на перевірку й до схвалення зникає з вітрини. Лише «в наявності» змінюється без перевірки.
- На вітрину (редактор вітрини → «🧩 Власні товари» або фільтр «Власні» у виборі товарів) можна додати **лише схвалені**.

## Що робите ви
Адмінка → **Партнери** → вкладка **Власні товари** (цифра — скільки чекає) → для кожного товару:
- **Хто відправляє покупцю:**
  - *Партнер сам* — він пакує й відправляє, оплату від покупця отримує сам; у замовленні заробіток через магазин = 0;
  - *Магазин* — ви вказуєте **закупівельну за одиницю**; заробіток партнера = ціна для покупця − закупівельна (видно одразу під полем).
- Коментар (для відхилення — причина) → **✅ Схвалити** або **✖️ Відхилити**. Партнер отримує повідомлення в бот.
- Схвалений товар можна перепризначити («Зберегти умови») або «Зняти з продажу».

Нові й змінені товари приходять і в бот менеджера (картка з фото).
У замовленні з вітрини такі позиції позначені «🧩 власний товар партнера · відправляє магазин/партнер сам».

## Технічно
- Таблиця партнерів: аркуш **«Власні товари партнерів»** (створиться сам), стовпець «Можливості» в аркуші «Партнери».
- Фото завантажуються на imgbb (той самий ключ, що для відгуків і вітрин).
- Оновити: скрипт **партнерів** і скрипт **вітрин** — свіжий код + нова версія розгортання.
