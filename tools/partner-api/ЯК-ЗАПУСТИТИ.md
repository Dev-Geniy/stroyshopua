# Як запустити особистий кабінет партнера (≈10 хвилин, один раз)

Кабінет працює на окремому скрипті Google — так основні замовлення й заявки сайту не зачіпаються.
Дані партнерів і їхніх замовлень зберігаються в новій Google Таблиці.

## 1. Таблиця і скрипт
1. Відкрийте https://sheets.new — створиться нова таблиця. Назвіть її «Samostroy — партнери».
2. Меню **Розширення → Apps Script**.
3. Видаліть усе у файлі `Code.gs` і вставте вміст файлу `tools/partner-api/Code.gs` з GitHub (кнопка «Copy raw file»).
4. Натисніть 💾 **Зберегти**.

## 2. Пароль і Telegram
1. Ліворуч ⚙️ **Налаштування проєкту** → внизу **Властивості скрипта** → **Додати властивість**:
   - `ADMIN_PASS` — **той самий пароль, яким ви входите в адмінку**;
   - `TG_TOKEN` — токен Telegram-бота (можна скопіювати з властивостей основного скрипта);
   - `TG_CHAT` — ID чату для сповіщень (так само з основного скрипта).
2. **Зберегти властивості скрипта**.

Без `TG_TOKEN` і `TG_CHAT` кабінет працює, але сповіщень про нових партнерів і замовлення в Telegram не буде — лише в адмінці.

## 3. Розгортання
1. Угорі праворуч **Розгорнути → Нове розгортання**.
2. Шестерня «Виберіть тип» → **Вебзастосунок**.
3. «Виконувати як» — **Я**; «Хто має доступ» — **Усі**.
4. **Розгорнути** → Google попросить дозволи → оберіть свій акаунт → «Додатково» → «Перейти до проєкту» → **Дозволити**.
5. Скопіюйте **URL вебзастосунку** (закінчується на `/exec`).

## 4. Підключення до сайту
1. На GitHub відкрийте `config.js` → олівець ✏️.
2. У рядку `papi:''` вставте адресу між лапками: `papi:'https://script.google.com/macros/s/…/exec',`
3. **Commit changes**. За 1–2 хвилини кабінет https://samostroy.shop/kabinet.html запрацює, а в адмінці з’явиться розділ «Партнери» з даними.

## Якщо змінюєте код скрипта
Розгорнути → **Керувати розгортаннями** → олівець → Версія: **Нова версія** → Розгорнути. Адреса залишається та сама.

## Що де
- Аркуш «Партнери» — акаунти (паролі зберігаються лише у вигляді хешу).
- Аркуш «Замовлення партнерів» — усі замовлення з кабінету.
- Рівні й маржа (Starter 10%, Pro 15%, Team 20%) — на початку `Code.gs`, змінна `LEVELS`. Ці ж відсотки показує кабінет і адмінка.
- Забув пароль партнер → Адмінка → Партнери → партнер → «Скинути пароль» → надішліть йому тимчасовий пароль.
