# Три Telegram-боти Samostroy Shop (≈20 хвилин, один раз)

| Бот | Для кого | Що вміє | Де працює |
|---|---|---|---|
| **Samostroy Admin** | власник (ви) | усі замовлення, заявки, відгуки, партнери й замовлення партнерів — з кнопками статусів; ТТН відповіддю; «📊 Сьогодні», «🆕 Нові», пошук; звіт щоранку о 9:00; відповіді клієнтам і партнерам | основний скрипт (`tools/main-api/Code.gs`) |
| **Samostroy Shop** | покупці | каталог прямо в Telegram, статус замовлення й ТТН, «Мої замовлення» за номером телефону, питання менеджеру | основний скрипт |
| **Samostroy Drop** | партнери-дропшипери | Mini App кабінету, нові замовлення, статуси, ТТН, виплати | скрипт кабінету партнерів (`tools/partner-api/Code.gs`) |

Аватарки ботів — `tools/bots/samostroy-admin.png`, `samostroy-shop.png`, `samostroy-drop.png`.

## Крок 1. Створіть ботів у @BotFather
У Telegram відкрийте **@BotFather** (з синьою галочкою) і для кожного бота:
1. `/newbot` → назва → ім’я користувача (латиницею, закінчується на `bot`). Якщо ім’я зайняте — додайте `_ua` або цифри.
   - **Samostroy Admin** → напр. `samostroy_admin_bot`
   - **Samostroy Shop** → напр. `samostroy_shop_bot`
   - **Samostroy Drop** → напр. `samostroy_drop_bot`
2. BotFather надішле **токен** (`1234567890:AA…`). Збережіть три токени в нотатки — кожен підписаний, якого бота.
3. Аватарка: `/setuserpic` → оберіть бота → надішліть картинку (як фото).
4. Для адмін-бота (необов’язково): `/setjoingroups` → бот → **Disable**, щоб його не додали в чужі групи.

Токен — як пароль: нікому не надсилайте й не показуйте на скриншотах.

## Крок 2. Основний скрипт магазину (замовлення з сайту)
Потрібен той проєкт Apps Script, адреса якого закінчується на `…MonN4w/exec` (як `api` у config.js).
Як перевірити: у проєкті **Розгорнути → Керувати розгортаннями** — там видно URL вебзастосунку.

1. Відкрийте файл `Code.gs` → виділіть увесь код (Ctrl+A) → вставте новий з
   https://raw.githubusercontent.com/Dev-Geniy/stroyshopua/main/tools/main-api/Code.gs → 💾 **Зберегти**.
2. ⚙️ **Налаштування проєкту → Властивості скрипта → Змінити**:
   - `BOT_TOKEN` — замініть на токен **Samostroy Admin**;
   - додайте `CLIENT_BOT_TOKEN` — токен **Samostroy Shop**;
   - `CHAT_ID` — **видаліть** (це чат старого бота; новий заповниться сам після `/login`);
   - `ADMIN_PASS` — не змінюйте.
   **Зберегти властивості скрипта**.
3. **Розгорнути → Керувати розгортаннями** → олівець ✏️ → Версія: **Нова версія** → **Розгорнути**.
   Google попросить дозволи → свій акаунт → «Додатково» → «Перейти до проєкту» → **Дозволити**. Адреса не зміниться.
4. Угорі редактора у списку функцій оберіть **setupBots** → **▶ Виконати**. Унизу в «Журналі виконання» має бути:
   `✓ Адмін-бот @…: підключено`, `✓ Клієнтський бот @…: підключено`, `✓ Ранковий звіт о 9:00`.
5. У Telegram відкрийте свого **Samostroy Admin** → **Почати** → напишіть `/login ваш_пароль_адмінки`
   (бот одразу видалить повідомлення з паролем). Відповідь: «✅ Готово! Цей чат підключено…».
6. Надішліть адмін-боту `/id` — він покаже **ID вашого чату** (число). Воно потрібне в кроці 3.

## Крок 3. Скрипт кабінету партнерів
Проєкт, адреса якого закінчується на `…227mI/exec` (як `papi` у config.js), таблиця «Samostroy — партнери».

1. Замініть код на https://raw.githubusercontent.com/Dev-Geniy/stroyshopua/main/tools/partner-api/Code.gs → 💾 **Зберегти**.
2. **Властивості скрипта**:
   - `ADMIN_PASS` — той самий пароль адмінки;
   - `TG_TOKEN` — токен **Samostroy Admin** (той самий, що BOT_TOKEN у кроці 2);
   - `TG_CHAT` — ID вашого чату з кроку 2.6;
   - `DROP_BOT_TOKEN` — токен **Samostroy Drop**.
3. **Розгорнути → Керувати розгортаннями** → ✏️ → **Нова версія** → **Розгорнути** → дозволи.
4. https://samostroy.shop/admin.html → **Налаштування** → блок «Telegram-бот партнерів» → **Підключити бота** → **Тестове повідомлення** (прийде в Samostroy Admin).

## Крок 4. Перевірка
1. Оформіть на сайті тестове замовлення → в адмін-боті з’явиться картка з кнопками «✅ Підтвердити / ❌ Скасувати».
2. На сторінці подяки натисніть **«Отримувати статус і ТТН у Telegram»** → відкриється Samostroy Shop → «Почати».
3. В адмін-боті: «✅ Підтвердити» → «🚚 Відправлено · ТТН» → надішліть номер відповіддю → у клієнтському боті прийдуть статус і ТТН з кнопкою «Відстежити».
4. Напишіть щось у Samostroy Shop як клієнт → питання прийде в адмін-бот → відповідайте свайпом (Reply) — відповідь піде клієнту.
5. Тестове замовлення видаліть в адмінці (картка → «Видалити»).

## Як користуватися адмін-ботом
- **Картки** нових замовлень (🛒), заявок (🤝), відгуків (⭐), партнерів і замовлень партнерів (📦) з кнопками. Після натискання картка оновлюється й показує, хто й коли змінив статус.
- **ТТН**: «🚚 Відправлено · ТТН» → надішліть номер відповіддю на повідомлення бота.
- **📊 Сьогодні** — продажі за сьогодні/вчора/7 днів, середній чек, що не оброблено. **🆕 Нові** — необроблені з кнопками. **🔎 Пошук** або просто надішліть номер телефону / № замовлення / ТТН.
- **Відповісти клієнту чи партнеру** — Reply на його повідомлення в боті.
- Щоранку о 9:00 — короткий звіт. `/logout` — відключити чат. Підключити ще один чат чи групу менеджерів — `/login пароль` у ньому.

## Клієнтський бот
- Посилання на бота з’являється на сторінці подяки після замовлення (кнопка «Отримувати статус і ТТН у Telegram»). Посилання з підписом — чужі замовлення по ньому не відкрити.
- «📦 Мої замовлення» → «Поділитися номером»: бот знайде замовлення за телефоном (лише за власним номером Telegram-акаунта).
- Покупцю приходять: підтвердження, відправка з ТТН і кнопкою «Відстежити», «Дякуємо» з кнопкою «Залишити відгук», скасування. Коментарі менеджера клієнту не надсилаються.
- Кнопка «Каталог» відкриває сайт прямо в Telegram.

## Якщо бот не відповідає
- У редакторі основного скрипта запустіть **botStatus** — у журналі буде остання помилка Telegram для кожного бота.
- Запустіть **setupBots** ще раз. Якщо не допомогло — **useBotPolling** (резервний режим: відповідь до 1 хвилини). Повернутись — знову setupBots.
- Для бота партнерів — адмінка → Налаштування → блок бота.
- Після будь-якої зміни коду — **Нова версія** розгортання.

## Що змінилося в основному скрипті
- Додано стовпець «Telegram клієнта» (прихований) — хто з покупців стежить за замовленням.
- Заявки (опт, постачальники, франшиза, вакансії, анкета) і відгуки більше не показуються в Telegram як «Замовлення … Разом 0 ₴» — кожен тип має свою картку.
- Відповідь на замовлення містить посилання на клієнтського бота (`tg`), сайт показує кнопку.
- Усе інше (номери замовлень, захист від спаму, адмінка) — як було.
