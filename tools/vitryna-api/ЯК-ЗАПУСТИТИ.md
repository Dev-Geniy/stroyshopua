# Вітрини партнерів — запуск, вимкнення, відкат

Окремий модуль: партнер створює власний магазин (назва, логотип, кольори, товари, ціни), покупці замовляють на ньому,
замовлення приходять у кабінет партнера й в адмін-бот, ви пакуєте й відправляєте як завжди.

## Що де
| Частина | Файли | Що робить |
|---|---|---|
| Вітрина для покупців | `v/index.html`, `v/boot.js`, `v/store.js`, `v/store.css` | samostroy.shop/v/?адреса і samostroy.shop/v/адреса/ |
| Готові вітрини | `v/presets.js` | 9 шаблонів в один клік: оформлення, тексти, переваги й правило добору товарів з каталогу (лише в наявності). Нові шаблони додаються в цей файл |
| Статистика для партнера | `v/kstats.js` | Відвідувачі, джерела, воронка, товари, замовлення. Показується в кабінеті (вкладка «Вітрина») і в редакторі. Дані — аркуш «Статистика» (дії `v_ev`, `v_stats`) |
| Правила вітрини | `v/policy.js` | «Обмін і повернення» (#povernennya) і «Політика конфіденційності» (#pryvatnist) у дизайні кожної вітрини. Повернення — копія правил `tools/povernennya.md`: змінюєте там — оновіть і тут |
| Редактор для партнера | `v/edit.html`, `v/edit.js` | samostroy.shop/v/edit.html (вхід — як у кабінет) |
| Модерація для вас | `v/admin.html` | samostroy.shop/v/admin.html |
| Віджет на сайт партнера | `v/embed.js` | код вставки — у редакторі |
| Налаштування модуля | `v/config.js` | вмикач, адреса скрипта, дані продавця |
| Сервер | `tools/vitryna-api/Code.gs` | окремий скрипт Google з таблицею «Samostroy — вітрини» |
| Короткі посилання | `v/<адреса>/index.html` | створюються кнопкою «Схвалити» (ключ GitHub) |

**Точки дотику з рештою сайту** (усе — лише посилання, їх можна прибрати без наслідків):
1. `kabinet.js` — вкладка «Вітрина» (NEW, `vVit` — статистика з `v/kstats.js`), промоблок `vitPromo` на «Огляді», кнопки «🏪 Моя вітрина» / «Створити вітрину» у «Мої товари», курс у блоці «Курси»; стилі `.kb-tv` і `.kb-vit` у `kabinet.html` (+ іконка `i-store`).
2. `app/app.js` — блок `.vit` на головній, пункти «Моя вітрина», «Статистика вітрини» й «Курс «Своя вітрина»» у профілі; стилі `.vit` в `app/app.css`, іконка `i-store` в `app/index.html`.
3. `admin.html` — пункт «Вітрини» в меню.
4. `tools/partner-api/Code.gs` — дія `ext_order` (+ спільна функція `makeOrder`): приймає замовлення з вітрини в «Замовлення партнерів».
5. `dropshipping.html` — секція `#vitryna` і питання в FAQ.
6. Блог: 4 статті про вітрини в `blog.json` (`vlasnyi-internet-mahazyn-bez-vkladen`, `nazva-i-lohotyp-mahazynu-z-shi`, `prodayuchi-teksty-dlya-internet-mahazynu`, `yak-prosuvaty-vitrynu-pershi-zamovlennya`).
7. Курс `course-vitryna.html` + `course-vitryna.js` (+ `og/course-vitryna.jpg`) і посилання на нього: меню «Партнерам» (`pnav`) на сторінках партнерів, `academy.html` (картка `.hot`), `academy.js`, `lk.html`, `sitemap.xml`, `tools/site.py`, `tools/og/make_og.py`.
8. `kb.js` — категорія «Своя вітрина» (статті `v-…`) і статті менеджера `m-vitryna…`.

Вітрини читають каталог `app/catalog.json` і сторінки товарів `p/` — нічого в них не змінюючи. Вітрини закриті від пошукових систем (noindex), щоб не конкурувати з samostroy.shop.

## Запуск (≈10 хвилин, один раз)
1. https://sheets.new → назвіть таблицю **«Samostroy — вітрини»** → **Розширення → Apps Script**.
2. Замініть код на https://raw.githubusercontent.com/Dev-Geniy/stroyshopua/main/tools/vitryna-api/Code.gs → 💾 **Зберегти**.
3. ⚙️ **Налаштування проєкту → Властивості скрипта**:
   - `ADMIN_PASS` — той самий пароль адмінки;
   - `TG_TOKEN` — токен адмін-бота (як у скрипті партнерів), необов’язково;
   - `TG_CHAT` — ID вашого чату з адмін-ботом, необов’язково.
4. У списку функцій оберіть **setup** → **▶ Виконати** → дозволи. У журналі мають бути три ✓ (аркуші, каталог, зв’язок з кабінетом партнерів).
5. **Розгорнути → Нове розгортання** → ⚙️ **Вебзастосунок** → «Виконувати як»: **Я**, «Хто має доступ»: **Усі** → **Розгорнути** → скопіюйте URL (`…/exec`).
6. Впишіть цей URL у `v/config.js` → `api: '…'` (або надішліть його мені).
7. **Скрипт кабінету партнерів**: вставте свіжий `tools/partner-api/Code.gs` → **Керувати розгортаннями → Нова версія** (потрібна дія `ext_order`).
8. Продавець на вітринах: за замовчуванням — «інтернет-магазин Samostroy Shop» (`v/config.js` → `seller: ''`). Партнер може вписати свій ФОП у редакторі (крок «Контакти й тексти») — тоді на його вітрині й у її правилах продавцем показується його ФОП.
9. Після оновлення `tools/vitryna-api/Code.gs` (напр. поле `fop`) — **Розгорнути → Керувати розгортаннями → ✏️ → Нова версія → Розгорнути**. URL не змінюється.

## Статистика
Вітрина рахує (без персональних даних покупців): перегляди, нових відвідувачів за день, хто відкрив товар / додав у кошик / почав оформлення, звідки прийшов (мітка `?src=ig|tt|tg|viber|fb|qr`, `utm_source` або сайт-джерело) і замовлення з сумою. Усе складається в аркуш **«Статистика»** (один рядок на вітрину, 120 днів, по товарах — 45 днів). Після оновлення коду скрипта вітрин зробіть **Нову версію** розгортання — аркуш створиться сам.

## Як працює
1. Партнер: кабінет → «Мої товари» → **«🏪 Моя вітрина»** (або Telegram → Профіль → «Моя вітрина»). Заповнює назву, адресу, логотип, обкладинку, шаблон, колір, шрифт, товари, націнку, контакти → **«Опублікувати вітрину»**.
2. Вітрина одразу працює за технічним посиланням `samostroy.shop/v/?адреса`; вам в адмін-бот приходить «Нова вітрина на модерації».
3. Ви: адмінка → **Вітрини** → **«Схвалити»** — з’являється коротке посилання `samostroy.shop/v/адреса/` з назвою й логотипом у прев’ю (потрібен ключ GitHub на цьому пристрої — той самий, що для відгуків).
4. Покупець замовляє (оплата при отриманні) → замовлення з’являється в кабінеті партнера з позначкою «Вітрина», в адмін-боті — «🏪 з вітрини». Далі як завжди.

**Ціни:** вітрина не може продавати дешевше за сайт. Націнка у %, округлення (до 10 ₴ або «на 9»), своя ціна на окремі товари. Сервер вітрин сам перераховує суму за каталогом — підробити ціну з браузера не вийде.

**Модерація:** «Вимкнути» — покупці бачать «Вітрина тимчасово недоступна». «Оновити прев’ю посилання» — якщо партнер змінив назву чи логотип після схвалення. «Видалити» — прибирає вітрину й коротке посилання. Скарги покупців — вкладка «Скарги» (і повідомлення в адмін-бот).

## Вимкнути (без видалення)
`v/config.js` → `on: false` → Commit. За кілька хвилин усі вітрини показують «тимчасово недоступна», редактор — «Вітрини ще налаштовуються». Повернути — `on: true`.

## Повністю прибрати модуль
1. Видаліть папку `v/` і `tools/vitryna-api/` (або на GitHub: відкат коміту «Вітрини партнерів…»).
2. Приберіть посилання з пунктів 1–3 і 5–8 списку «Точки дотику» вище (пошук по файлах: `v/edit.html`, `course-vitryna`, `vitPromo`, `#vitryna`, `cat: 'shop'`, `m-vitryna`). Курс можна й залишити — він корисний і без вітрин, але тоді приберіть з нього кнопки «Відкрити редактор вітрини».
3. Дію `ext_order` у скрипті партнерів можна залишити — без вітрин її ніхто не викликає.
4. У скрипті вітрин: **Розгорнути → Керувати розгортаннями → Архівувати**. Таблицю «Samostroy — вітрини» можна залишити як архів.
Замовлення, що вже прийшли з вітрин, лишаються в кабінетах партнерів і в історії.
